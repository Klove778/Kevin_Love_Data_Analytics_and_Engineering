Portfolio project in development

Medicare provider analytics

Which services account for the most Medicare volume in Missouri, and how does the average payment per service vary by specialty and place of service?

Python ingestion pipeline

The planned pipeline will pull CMS provider and service records, retain each annual source release, and record row counts so a refresh can be checked against its input.

dbt transformations and tests

The base model will preserve one row per reporting year, provider, service code, and place of service. A reporting model will weight average payments by service count. Tests will check the row grain and reconcile published service totals to the source extract.

Tableau Public dashboard

The planned workbook will let visitors filter by specialty and place of service, rank services by volume, and see how many services underlie each payment comparison.

AI analytics agent

A visitor will be able to ask which services drive volume for a specialty. The proposed agent will query the same reporting model as Tableau and show its filters, SQL, and source year alongside its answer.
